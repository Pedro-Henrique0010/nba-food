# 🏀 NBA Food Game

> Jogo educativo de classificação de alimentos com temática de basquete!

## 🎮 Como Jogar

Um alimento aparece no centro da quadra. Clique na **cesta correta** para arremessá-lo!

| Cesta | Categoria | Exemplo |
|-------|-----------|---------|
| 🟢 Verde | In Natura / Natural | 🍎 Maçã, 🍌 Banana |
| 🟡 Amarelo | Minimamente Processado | 🥛 Iogurte, 🍚 Arroz |
| 🔴 Vermelho | Ultraprocessado | 🍪 Biscoito, 🥤 Refrigerante |

- ✅ Acertou → avança para o próximo nível
- ❌ Errou → recomeça do nível 1
- 🏆 Complete os 7 níveis para vencer!

## 🕹️ Níveis

| Nível | Alimento | Categoria |
|-------|----------|-----------|
| 1 | 🍎 Maçã | In Natura |
| 2 | 🥛 Iogurte Natural | Minimamente Processado |
| 3 | 🧃 Suco de Laranja Integral | Minimamente Processado |
| 4 | 🍪 Biscoito Recheado | Ultraprocessado |
| 5 | 🍚 Arroz Branco Cozido | Minimamente Processado |
| 6 | 🥤 Refrigerante | Ultraprocessado |
| 7 | 🍌 Banana | In Natura |

## ⚙️ Tecnologias

- HTML5 + CSS3 + JavaScript puro (sem dependências!)
- Web Audio API para efeitos sonoros
- CSS animations para confete e arremesso
- Animação de arremesso em 2 fases: arco parabólico → queda no aro

## 🚀 Como rodar

Basta abrir o arquivo index.html no navegador. Não precisa de servidor!
